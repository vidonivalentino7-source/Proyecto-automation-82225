# Proyecto-automation-82225# QA Automation Project

## 📌 Description

Basic web automation testing project developed using Java, Selenium WebDriver, TestNG, and Maven.

The project follows the Page Object Model (POM) design pattern to organize and maintain automated tests.

## 🛠️ Technologies

- **Java** – Programming language
- **Selenium WebDriver** – Browser automation
- **TestNG** – Testing framework
- **Maven** – Dependency management
- **Page Object Model (POM)** – Design pattern

## 📁 Project Structure

```text
src/
├── main/java/
│   └── pages/
└── test/java/
    └── tests/
pom.xml
README.md
```

## 🎯 Objective

Practice web test automation by implementing automated test cases using Selenium WebDriver and TestNG, following the Page Object Model design pattern.

## 🚀 Run Tests

Execute the tests using Maven:

```bash
mvn test
```
